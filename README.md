# 💳 토스 스타일 심플 스마트 웹 가계부 (Household Budget)

> 토스 디자인 시스템(TDS) 기반의 플랫 미니멀 감성, 1:1:1 균등 대시보드 레이아웃, 월별/연간 실시간 결산 웹 가계부

🌐 **온라인 배포 주소**: https://hanb0303.github.io/household-budget/

---

## ✨ 핵심 기능

1. **토스/애플 디자인 시스템 기반의 초간결 미니멀 UI**
   - 브라우저 네이티브 요소를 배제한 프리미엄 커스텀 드롭다운 (`2026년 ∨`)
   - 애플/토스 감성의 세그먼트 컨트롤 (1~12월 전환, 월별/연간 뷰 전환)
   - 상단 KPI 요약 카드와 본문 3열 카드의 완벽한 1:1:1 가로 폭 일치

2. **완벽한 월별 회계 관리**
   - **1열 (들어온 돈)**: 기본 월급 + 부수입/환급/정산 내역 실시간 합산
   - **2열 (이번 달 소비)**: 카드별 청구 금액(신한/현대/국민/롯데 등) + 일상 소비 계좌이체 변동비 합산
   - **3열 (고정비 관리)**: 계좌 고정비(월세/대출이자/보험 등) + 카드 정기결제(구독/관리비 등)

3. **독립 메모 박스 (전체 월 공통 제공)**
   - 수입 박스 하단에 배치된 독립된 카드 박스
   - 총 수입/지출/순수익 회계 계산에 전혀 영향을 주지 않는 완전 격리 메모 공간
   - 각 월별 독립 저장 및 자체 총합 실시간 집계

4. **1년 연간 결산 요약 뷰**
   - 1월부터 12월까지의 월별 수입, 소비, 고정비, 순수익 흐름을 한눈에 비교
   - 연간 누적 합계 및 월평균 실적 자동 분석

5. **로컬 스토리지 자동 저장**
   - 모든 수정 사항은 브라우저(`localStorage`)에 즉시 보존되어 새로고침하거나 창을 닫아도 안전하게 유지됩니다.
